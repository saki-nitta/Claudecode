# Cowork-Workspace（外部AI連携用の回覧トレイ）

D:\toumei.shippo本体とは別の運用ルール。スマホ版Claude（Cowork）などにGoogleドライブ経由で資料を渡すための一時置き場。

## 使い方
- `input/` に読ませたい資料を置く（案件ごとにサブフォルダを切ってよい）
- `work/` は作業中の下書き置き場
- `output/` に完成品を置いてもらう
- サキがGoogleドライブへ手動で移す（自動同期なし）

## カテゴリ
- Content：Makuakeページ・ブログ・SNS文章など「書く」系
- Ops：GTカフェ・バトン市などイベント運営系
- Finance：経理・弥生関連
- Personal：プライベート
