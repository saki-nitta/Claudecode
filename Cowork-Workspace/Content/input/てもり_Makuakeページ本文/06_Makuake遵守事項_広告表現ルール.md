# Makuake遵守事項・広告表現ルール（本文執筆時に必ず守ること）

> 元ノート：20260629_doc_Makuake遵守事項チーム共有_draft_v1.md（Makuakeお申込書遵守事項／クオリティサポートプログラムより新田が要点整理）。違反すると違約金・掲載停止のリスクがあるため、Makuakeページ本文を書く際は必ずこれに従うこと。

## 広告表現ルール（最重要・執筆時に直接影響）

| 表現 | 可否 | 理由 |
|---|---|---|
| 「臨床心理士が**設計した**」 | ✅ OK | 事実に基づく正確な表現 |
| 「臨床心理士による**発達視点の設計**」 | ✅ OK | 同上 |
| 「臨床心理士が**監修**」 | ❌ NG | 優良誤認にあたる可能性 |
| 「臨床心理士が**推薦**」 | ❌ NG | 同上 |
| 「**唯一無二**の」「**世界一**の」等の絶対的表現 | ❌ NG | 誇張表現（不適切な広告表現＝25点の違反行為） |

## ページ本文に必ず記載すべき事項

### 製造委託先の公表義務（実行者ガイドライン第9条）
第三者への製造・デザイン委託は、サポーターへの事前公表なく行うのは禁止。以下の趣旨をページ本文に記載する：

> 「製品の製造は松森木工所（ima Design Lab）に、デザイン・パッケージは岩手アートディレクターズクラブに委託しています」

### 割引表示の根拠確約（実行者ガイドライン第3条13項）
早割・超早割で「通常価格◯◯円」と表示する場合、CF終了後も相当期間その価格で販売することを確約する必要がある。金額を確定する前に松森さんと合意しておくこと。

### 許認可の取得義務
リターンの製造・提供・配送に必要な許認可は必ず取得。**てもり（むくり）の場合：こどもPSCマークの取得が公開前提条件。**

## 禁止行為（本文・運用全般で注意）
- 自己応援購入・サクラ購入の禁止（家族・知人も対象）
- ステルスマーケティングに該当する行為
- リターン配送完了前に他販路（BASE・minne・店頭等）で同一商品を販売する行為
- 実行者関係者によるレビュー投稿・レビュー記載の強要
- 活動レポートは期間中最低1回・終了後は月1回以上の投稿義務（違反は掲載停止リスク）

## 変更が生じた場合
素材・樹種・加工方法・デザイン・サイズ等の大幅変更が生じた場合は、事前にキュレーターへ報告・サポーターへ通知が必要（サポーター不利益になる変更は全額返金等の責任を負う）。
